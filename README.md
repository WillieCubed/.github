# WillieCubed

Repositories owned by WillieCubed inherit their GitHub issue forms and pull request template from
this repository. GitHub applies them to every repository without its own copy, public or private.

The canonical files live in
[`WillieCubed/repository-tooling`](https://github.com/WillieCubed/repository-tooling) under
`community-health/`. [`SOURCE.json`](SOURCE.json) records the commit they came from and their
checksums. Changes begin in the tooling repository and are copied here, never edited here first.
